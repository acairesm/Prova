EXTENSÕES DO VS CODE (versão 1.137.0)
=====================================

1) VISUAL (temas e ícones)
--------------------------
  - zhuangtongfa.material-theme         One Dark Pro (tema em uso)
  - pkief.material-icon-theme           Material Icon Theme (ícones em uso)
  - enkia.tokyo-night                   Tokyo Night
  - ssmi.after-dark                     After Dark
  - guyutongxue.devcpp-theme            Dev-C++ Theme

Settings de visual (settings.json):
  "workbench.colorTheme": "One Dark Pro",
  "workbench.iconTheme": "material-icon-theme",
  "editor.cursorSmoothCaretAnimation": "on",
  "editor.cursorBlinking": "smooth",
  "editor.smoothScrolling": true,


2) JAVA
-------
  - vscjava.vscode-java-pack            Extension Pack for Java
  - redhat.java                         Language Support for Java (autocomplete Java)
  - oracle.oracle-java                  Java (Oracle)
  - vscjava.vscode-java-debug           Debugger for Java
  - vscjava.vscode-java-dependency      Project Manager for Java
  - vscjava.vscode-java-test            Test Runner for Java
  - vscjava.vscode-maven                Maven
  - vscjava.vscode-gradle               Gradle


3) IA
-----
  - anthropic.claude-code               Claude Code
