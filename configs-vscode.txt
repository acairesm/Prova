2) SETTINGS DO USUÁRIO (~/.config/Code/User/settings.json)
-----------------------------------------------------------
{
  "workbench.iconTheme": "material-icon-theme",
  "claudeCode.preferredLocation": "panel",
  "files.autoSave": "afterDelay",
  "git.autofetch": true,
  "github.copilot.chat.generateCommitMessage": false,
  "editor.columnSelection": true,
  "hediet.vscode-drawio.resizeImages": null,
  "workbench.colorTheme": "One Dark Pro",
  "js/ts.updateImportsOnFileMove.enabled": "always",
  "emmet.includeLanguages": {
    "javascript": "javascriptreact",
    "typescript": "typescriptreact",
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode",
  },
  "diffEditor.ignoreTrimWhitespace": false,
  "editor.cursorSmoothCaretAnimation": "on",
  "editor.cursorBlinking": "smooth",
  "editor.smoothScrolling": true,
  "jdk.telemetry.enabled": true,
}

O que cada uma faz:
  - files.autoSave = afterDelay        salva sozinho depois de alguns segundos
  - git.autofetch = true               busca atualizações do git sozinho
  - editor.columnSelection = true      seleção em coluna/bloco ativada
  - emmet.includeLanguages             Emmet (autocomplete de HTML) dentro de JS/TS (JSX)
  - js/ts.updateImportsOnFileMove      atualiza imports ao mover arquivo
  - [typescriptreact] defaultFormatter Prettier formata arquivos .tsx
  - cursorSmoothCaretAnimation / cursorBlinking / smoothScrolling   animações suaves
